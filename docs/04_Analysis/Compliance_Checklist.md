### 2.2 用户隐私保护指引配置

在微信公众平台配置以下内容：

```
Zentro 活动助手小程序收集以下用户信息：

1. 手机号：用于用户登录验证、活动报名、联系沟通
2. 微信昵称/头像：用于用户信息展示（可选）
3. 位置信息：用于活动地点导航（可选，需用户授权）

我们承诺：
- 仅在实现功能所必需的范围内使用用户信息
- 不向第三方出售用户信息
- 采取合理措施保护用户数据安全
- 用户可申请删除或注销账号

联系方式：【privacy@your-domain.com】
```

## 六、验证方法

### 6.1 功能验证

1. **账号注销**
   - 模拟用户注销
   - 验证数据库数据已删除
   - 验证冷静期内可撤销

2. **内容安全**
   - 输入敏感词
   - 验证返回 400 错误
   - 验证内容被拒绝发布

3. **频率限制**
   - 短时间内多次请求
   - 验证返回 429 错误

### 6.2 安全验证

1. **HTTPS**
   - 检查所有 API 是否使用 HTTPS
   - 检查证书是否有效

2. **数据脱敏**
   - 检查报名列表手机号是否脱敏
   - 检查日志中是否包含敏感信息

3. **Token 验证**
   - 检查未登录是否无法访问受保护接口
   - 检查 Token 过期是否正确处理

### 6.3 合规验证

1. **隐私政策**
   - 访问 `/legal/privacy.html` 确认可访问
   - 检查内容是否完整
   - 检查占位符是否已填充

2. **用户协议**
   - 访问 `/legal/terms.html` 确认可访问
   - 检查内容是否完整
   - 检查占位符是否已填充

3. **备案号**
   - 检查网站底部是否显示备案号
   - 检查备案号链接是否正确
