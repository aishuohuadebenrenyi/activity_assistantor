## 5. 验证方法

### 5.1 功能验证
1. **账号注销**：模拟用户注销，验证数据库数据已删除
2. **内容安全**：输入敏感词，验证返回 400 错误
3. **频率限制**：短时间内多次请求，验证返回 429 错误

### 5.2 安全验证
1. **HTTPS**：检查所有 API 是否使用 HTTPS
2. **数据脱敏**：检查报名列表手机号是否脱敏
3. **Token 验证**：检查未登录是否无法访问受保护接口
