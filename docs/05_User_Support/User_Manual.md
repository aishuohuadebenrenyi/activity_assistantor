# 用户使用手册

## 1. 快速开始

### 第一步：创建活动
1. 点击底部 **"+" 创建** 按钮
2. 填写活动信息（名称、时间、地点）
3. 点击 **立即创建活动**

### 第二步：邀请报名
1. 进入活动详情页，点击 **分享**
2. 将海报或链接分享到微信群
3. 用户扫码即可报名

### 第三步：现场签到
1. 进入 **报名管理** 列表
2. 点击参与者右侧 **签到** 按钮
3. 或使用扫码功能扫描参与者二维码

---

## 2. 功能说明

### 2.1 活动管理
- **创建活动**：填写名称、类型、时间、地点、人数、描述
- **编辑活动**：仅组织者可编辑
- **删除活动**：级联删除报名/签到记录
- **活动列表**：支持状态筛选、关键词搜索

### 2.2 报名与签到
- **小程序端**：在线报名、查看电子票、扫码签到
- **App 端**：扫码核销、手动签到、名单管理

### 2.3 数据导出
- 支持将报名名单以 CSV 格式发送至邮箱

---

## 3. 常见问题

**Q: 创建活动时键盘挡住了按钮怎么办？**
A: 页面会自动调整，确保按钮可见。

**Q: 报名页的"导出"可以直接下载吗?**
A: 当前版本导出功能为发送到邮箱。

**Q: 如何恢复已注销的账号?**
A: 在 15 天冷静期内重新登录即可恢复。
