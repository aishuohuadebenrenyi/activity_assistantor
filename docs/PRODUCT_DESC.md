# 活动帮手 (Activity Assistant) 产品说明书

## 1. 产品概述

**活动帮手** 是面向活动组织者的移动端活动管理应用，聚焦“创建活动—管理报名—签到跟进—结果沉淀”闭环，帮助用户在手机端完成活动全流程管理。

## 2. 产品定位

- **目标用户**：社区运营、企业行政/HR、培训负责人、社群组织者。
- **核心价值**：快速发起、过程可控、数据可见。
- **产品形态**：轻量级移动应用，强调低学习成本与高频操作效率。

## 3. 页面与交互设计

### 3.1 全局导航结构
- 底部 TabBar 三个主入口：**首页**、**创建**、**我的**。
- 非 Tab 页（如详情、报名人员、分享、编辑资料）采用页面内跳转返回。
- 全局背景与导航栏风格统一，提升页面过渡连贯性。

### 3.2 首页（活动列表）
- 顶部展示活动统计卡片，列表区展示活动项。
- 搜索区为**折叠式入口**：点击列表头部搜索按钮后展开“搜索 + 状态筛选”。
- 列表支持按状态筛选（全部/进行中/即将开始/已结束）与关键词检索（名称/地点）。
- 提供“新建”快捷入口与空状态引导按钮。
- TabBar 支持滚动联动显隐；在搜索区展开时保持 TabBar 可见以避免交互抖动。

### 3.3 创建页
- 表单覆盖名称、类型、日期、时间、地点、人数上限、活动介绍。
- 支持键盘高度监听与底部动态避让，避免输入时遮挡提交区域。
- 提交按钮文案为 **“立即创建活动”**，支持提交状态保护，避免重复提交。

### 3.4 活动详情页
- 分为“活动统计”“活动详情摘要”“详细信息表单”“活动工具”四个区域。
- “详细信息”区域支持折叠与编辑，编辑入口位于**详细信息模块头部右上角**。
- 工具区提供“报名情况”“分享”快捷操作。
- 对无效活动 ID 提供异常态提示和返回首页入口。

### 3.5 报名人员页
- 顶部展示报名统计（报名人数、已签到、未签到、签到率）。
- “报名人员”模块支持搜索、筛选、签到状态切换。
- **导出入口位于报名人员模块头部右侧**，当前为占位能力（提示开发中）。

### 3.6 我的页与资料页
- 我的页展示个人数据看板与通用设置入口（主题、通知、帮助等）。
- 编辑资料页支持修改基础信息、退出登录与注销账号。

## 4. 关键体验原则

- **信息密度平衡**：通过卡片分区承载统计、内容与工具，降低认知负担。
- **关键动作前置**：创建、编辑、导出等操作放在对应模块头部，提升可发现性。
- **状态清晰反馈**：点击态、空态、异常态、保存成功提示保持一致。
- **安全区适配**：底部内容避让系统安全区与键盘，保证可见可点。

## 5. 当前版本范围

- **已实现**：活动创建、列表浏览、筛选搜索、详情编辑、报名签到、个人中心与资料管理。
- **部分实现/占位**：报名导出功能（当前为“开发中”提示）。

## 6. 版本信息

- **当前版本**：v6.0
- **开发技术**：uni-app x（UTS）
- **运行平台**：iOS / Android

## 7. 技术架构

### 7.1 前端架构
- **框架**：uni-app x (基于 Vue 3 + UTS)
- **编译模式**：纯原生渲染 (App-Nvue)，保障高性能体验。
- **状态管理**：Vue Reactivity (Pinia 风格)。

### 7.2 后端架构
- **运行环境**：阿里云 Web 函数 (Serverless FC)
- **开发语言**：Python 3.9+
- **Web 框架**：Flask
- **数据库**：MySQL (RDS)
- **API 规范**：RESTful API

## 8. 数据与安全

- **数据存储**：云端持久化存储，支持多端同步。
- **用户认证**：基于 JWT (JSON Web Token) 的身份验证。
- **隐私保护**：手机号等敏感信息加密存储。
