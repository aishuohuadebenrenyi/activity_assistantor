# 测试计划 (Test Plan)

## 1. 测试目标
确保 "活动帮手" 应用在发布前满足功能完整性、稳定性及用户体验要求。

## 2. 测试范围
- **功能测试**: 核心业务流程（创建、报名、签到、管理）。
- **兼容性测试**: iOS/Android 主流机型适配。
- **网络测试**: 弱网、断网、网络切换场景。
- **性能测试**: 列表加载速度、内存占用。

## 3. 测试用例清单 (Checklist)

### 3.1 核心功能
- [ ] **用户登录**:
  - [ ] 手机号格式校验通过。
  - [ ] 验证码倒计时正常。
  - [ ] 登录成功后 token 本地存储。
- [ ] **活动管理**:
  - [ ] 创建活动：表单必填项校验，提交后跳转成功页。
  - [ ] 活动列表：下拉刷新，上拉加载更多（如有），状态筛选准确。
  - [ ] 活动详情：信息展示完整，编辑功能正常保存。
- [ ] **报名与签到**:
  - [ ] 用户报名：防重复提交。
  - [ ] 管理员签到：状态实时更新，人数统计准确。
  - [ ] 扫码签到（如已实现）：识别二维码并自动签到。

### 3.2 离线与网络容错 (关键)
- [ ] **断网启动**:
  - [ ] App 能正常打开，显示本地缓存的列表数据。
  - [ ] 顶部提示“网络已断开”。
- [ ] **离线操作**:
  - [ ] 断网状态下点击“创建活动”，提示“已存入离线队列”或类似反馈。
  - [ ] 恢复网络后，App 自动发起重试，数据同步成功。
- [ ] **弱网环境**:
  - [ ] 请求超时（>10s）时有友好提示，而非白屏或崩溃。

### 3.3 UI/UX 细节
- [ ] **空状态**: 列表为空时显示引导插画。
- [ ] **加载态**: 数据请求期间显示 Loading 转圈。
- [ ] **键盘避让**: 输入框不被键盘遮挡。
- [ ] **权限请求**: 相机/定位权限拒绝后有引导提示。

## 4. 发布验收标准
1.  无 P0 级（崩溃、白屏、数据丢失）Bug。
2.  核心流程（创建->报名->签到）在 4G/WiFi 下 100% 通过。
3.  离线模式下基础浏览功能可用。
