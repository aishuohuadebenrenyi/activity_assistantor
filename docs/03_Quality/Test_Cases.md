## 3. 缺陷等级定义 (Bug Severity)

*   **P0 - Blocker (阻碍发布)**：
    *   核心功能瘫痪 (如无法登录、无法创建活动)。
    *   数据丢失或严重错乱。
    *   App 崩溃 (Crash) 或闪退。
*   **P1 - Critical (严重)**：
    *   主要功能部分失效 (如搜索无结果、签到状态不更新)。
    *   严重的 UI 问题导致无法操作 (如按钮被遮挡)。
*   **P2 - Major (一般)**：
    *   次要功能缺陷 (如筛选不准确)。
    *   UI 样式问题 (如错位、字体颜色错误)。
    *   错误提示文案不友好。
*   **P3 - Minor (轻微)**：
    *   建议性改进。
    *   偶现的轻微体验问题。
