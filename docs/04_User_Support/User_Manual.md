# 活动帮手 (Activity Assistant) 用户使用手册

## 1. 快速开始 (Quick Start)

### 1.1 三步开启您的活动管理之旅

**第一步：创建活动**
1.  打开 App，点击底部中间的 **“+ 创建”** 按钮。
2.  填写活动基本信息（名称、时间、地点）。
3.  点击 **“立即发布”**，系统会自动生成活动专属链接和二维码。

**第二步：邀请报名**
1.  在活动详情页，点击右上角的 **“分享”** 图标。
2.  将海报或链接分享到微信群、朋友圈。
3.  用户点击链接即可直接报名，数据实时同步到您的 App。

**第三步：现场签到**
1.  活动当天，打开 App 进入 **“报名管理”** 列表。
2.  点击参与者名字右侧的 **“签到”** 按钮，或使用右上角的扫码功能（扫描参与者的二维码）。
3.  实时查看已到/未到人数统计。

---

## 2. 浏览活动

### 2.1 首页浏览
- 登录成功后，默认进入“首页”。
- 可上下滑动查看活动列表，并查看顶部活动统计数据。
- 向下浏览时，底部菜单栏可能自动隐藏；向上滑动会恢复显示。
- 当搜索区处于展开状态时，底部菜单栏保持显示，便于快速切换页面。

### 2.2 筛选活动
- 点击“活动列表”标题右侧的 🔍 按钮，展开搜索与筛选区域。
- 输入关键词可按活动名称/地点搜索。
- 可切换“全部、进行中、即将开始、已结束”筛选活动。

## 3. 发布活动

1. 点击底部菜单栏中间的 **“创建”** 按钮。
2. 在创建页面填写活动信息：
   - **活动名称**：输入简洁明了的标题。
   - **活动类型**：点击选择合适的分类（如会议、培训等）。
   - **日期与时间**：选择活动开始的具体时间。
   - **地点**：输入活动举办的具体地址。
   - **活动详情**：详细描述活动内容、流程或注意事项。
3. 确认信息无误后，点击底部的 **“立即创建活动”** 按钮。
4. 发布成功后，系统将自动跳转回首页，您可以在列表中看到刚刚发布的活动。
5. 输入过程中若键盘弹起，页面会自动上移并增加底部留白，避免遮挡提交按钮。

## 4. 活动详情与报名管理

### 4.1 查看活动详情
1. 在首页点击任一活动卡片，进入“活动详情”。
2. 页面会展示活动统计、活动摘要和详细信息。
3. 若活动无效（已删除或不存在），页面会提示并可返回首页。

### 4.2 编辑活动信息
1. 在“详细信息”模块右上角点击 **“编辑”**。
2. 修改活动名称、时间、地点、人数等内容。
3. 点击 **“完成”** 或“保存修改”提交更新。

### 4.3 管理报名与签到
1. 在活动详情页点击“报名情况”进入“报名人员”页面。
2. 使用搜索和筛选快速定位人员。
3. 点击人员右侧状态可执行签到/取消签到。
4. 点击“报名人员”模块右上角 **“导出”** 可触发导出入口（当前版本为开发中提示）。

### 4.4 分享活动
1. 在活动详情页点击“分享”。
2. 可复制分享链接并转发给参与者。

## 5. 个人中心与设置

点击底部菜单栏右侧的 **“我的”** 按钮进入个人中心。

### 5.1 查看数据
在个人中心顶部，您可以直观地看到您的活动统计数据：
- **总活动**：您发布的活动总数。
- **进行中**：当前尚未结束的活动数量。
- **总参与**：所有活动的累计报名人次。

### 5.2 编辑资料
1. 点击顶部的用户卡片（或头像区域）。
2. 进入“编辑资料”页面。
3. 您可以修改 **用户名**、**手机号**、**官方认证信息** 和 **个人简介**。
4. 修改完成后，点击 **“保存修改”** 按钮。

### 5.3 退出与注销
在“编辑资料”页面底部：
- **退出登录**：点击“退出登录”并确认，将返回登录页。
- **注销账号**：点击“注销账号”，此操作将永久清空您的数据，请谨慎操作。

### 5.4 通用设置
在个人中心页面：
- **显示主题**：点击可切换深色/浅色模式或跟随系统。
- **通知设置**：点击可开启或关闭活动提醒通知。
- **帮助与支持**：提供意见反馈入口及关于应用的信息。

## 6. 常见问题 (FAQ)

**Q: 为什么我看不到底部的菜单栏？**
A: 首页向下滑动时菜单栏会自动隐藏。向上滑动即可恢复；若搜索区已展开，菜单栏会保持显示。

**Q: 创建活动时键盘挡住了提交按钮怎么办？**
A: 我们已优化了输入体验，键盘弹出时页面会自动调整高度，确保您能看到正在输入的内容和底部的按钮。

**Q: 报名页的“导出”可以直接下载文件吗？**
A: 当前版本“导出”为预留入口，点击后会提示“导出功能开发中”。
