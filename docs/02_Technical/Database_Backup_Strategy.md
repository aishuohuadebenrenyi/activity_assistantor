## 一、备份策略概述

### 1.1 备份目标

- 确保数据安全，防止数据丢失
- 支持快速恢复，最小化业务中断时间
- 满足合规要求，保留历史数据
- 支持异地容灾，防止单点故障

### 1.2 备份原则

| 原则 | 说明 |
|------|------|
| **3-2-1原则** | 3份副本、2种介质、1份异地 |
| **自动化** | 备份过程全自动，无需人工干预 |
| **可验证** | 定期验证备份可用性 |
| **安全性** | 备份文件加密存储 |
| **分级保留** | 按时间分级保留，优化存储成本 |

## 二、备份类型与频率

### 2.1 备份类型

| 类型 | 说明 | 数据量 | 恢复时间 |
|------|------|--------|----------|
| **全量备份** | 完整数据库导出 | 大 | 快 |
| **增量备份** | 基于二进制日志的变更 | 小 | 慢 |
| **结构备份** | 仅表结构，用于快速重建 | 极小 | 极快 |

### 2.3 定时任务配置

```bash

# 添加以下任务
# 全量备份 - 每日凌晨2点
0 2 * * * /opt/scripts/backup.sh --type=full --upload >> /var/log/backup.log 2>&1
```

## 三、备份保留策略

### 3.1 保留周期

| 备份类型 | 保留周期 | 存储位置 | 说明 |
|----------|----------|----------|------|
| 日备份 | 30天 | 本地 + OSS | 可恢复最近30天任意时间点 |
| 周备份 | 12周 | 本地 + OSS | 仅保留周日备份 |
| 月备份 | 12个月 | OSS | 仅保留每月1日备份 |

## 五、备份加密方案

### 5.1 加密配置

```bash
# 生成加密密钥（保存到安全位置）
openssl rand -base64 32 > /etc/backup/encryption.key
chmod 600 /etc/backup/encryption.key

# 环境变量配置
export ENCRYPTION_ENABLED=true
export ENCRYPTION_KEY=$(cat /etc/backup/encryption.key)
```

### 5.2 加密流程

```
原始备份 → GZIP压缩 → AES-256加密 → SHA256校验 → 上传OSS
```

### 5.3 解密恢复

```bash
# 解密备份文件
openssl enc -aes-256-cbc -d -in backup.sql.gz.enc -out backup.sql.gz -pass pass:<key>

# 解压
gunzip backup.sql.gz

# 恢复
mysql -u root -p zentro < backup.sql
```

### 6.3 恢复测试脚本

```bash
#!/bin/bash
# 恢复测试脚本

TEST_DB="zentro_test"
BACKUP_FILE=$1

# 创建测试数据库
mysql -u root -p -e "DROP DATABASE IF EXISTS $TEST_DB; CREATE DATABASE $TEST_DB;"

# 恢复备份
mysql -u root -p $TEST_DB < $BACKUP_FILE

# 验证数据
TABLES=$(mysql -u root -p $TEST_DB -e "SHOW TABLES;" | wc -l)
USERS=$(mysql -u root -p $TEST_DB -e "SELECT COUNT(*) FROM user;" | tail -1)
ACTIVITIES=$(mysql -u root -p $TEST_DB -e "SELECT COUNT(*) FROM activity;" | tail -1)

echo "恢复验证结果："
echo "  表数量: $TABLES"
echo "  用户数: $USERS"
echo "  活动数: $ACTIVITIES"

# 清理测试数据库
mysql -u root -p -e "DROP DATABASE $TEST_DB;"
```

## 八、监控与告警

### 8.1 监控指标

| 指标 | 阈值 | 告警级别 |
|------|------|----------|
| 备份执行时间 | > 2小时 | WARNING |
| 备份文件大小 | < 1MB 或 > 预期值 | WARNING |
| 备份失败 | 任何失败 | CRITICAL |
| 存储空间使用率 | > 80% | WARNING |
| 存储空间使用率 | > 90% | CRITICAL |
| OSS上传失败 | 任何失败 | CRITICAL |

### 8.2 告警通知

```yaml
# 告警配置示例
alerts:
  - name: backup_failed
    condition: backup_status != "success"
    severity: critical
    channels:
      - email: ops@zentro.app
      - sms: "+8613800138000"
      - webhook: https://hooks.feishu.cn/xxx
  
  - name: storage_warning
    condition: storage_usage > 80%
    severity: warning
    channels:
      - email: ops@zentro.app
```
