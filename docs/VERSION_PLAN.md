# Zentro 版本计划

## 当前版本: v1.0.0

### 平台定位

本版本采用**双平台差异化设计**，针对不同用户群体提供专属功能：

| 平台 | 用户角色 | 核心功能 |
|------|----------|----------|
| **App 端** | 活动主办方 | 创建活动、管理报名、核销签到、数据分析 |
| **小程序端** | 活动参与者 | 报名活动、查看票据、取消报名、联系主办方 |

### 权限控制

#### 前端权限验证

1. **活动详情页**
   - 非主办方：隐藏编辑、删除、报名情况按钮
   - 主办方：显示完整管理功能

2. **报名人员页**
   - 非主办方：显示"无访问权限"提示，禁止访问
   - 主办方：正常显示报名列表

3. **票据页**
   - 仅显示取消报名和返回按钮
   - 移除扫码签到功能（签到由主办方操作）

#### 后端权限验证

1. **编辑/删除活动**：验证 `activity.user_id == request.user.id`
2. **查看报名列表**：验证 `activity.user_id == request.user.id`
3. **签到操作**：验证 `activity.user_id == request.user.id`
4. **导出名单**：验证 `activity.user_id == request.user.id`

### 安全机制

#### 签到码安全

签到码采用 HMAC 签名验证机制：

```
格式: CHECKIN:activity_id:registration_id:timestamp:signature
```

- **签名算法**: HMAC-SHA256（取前16位）
- **密钥**: 环境变量 `QR_SECRET_KEY`
- **有效期**: 7天
- **验证项**: 
  - 时间戳有效性
  - 签名正确性
  - 活动ID匹配

#### 数据脱敏

- 手机号脱敏：`138****5678`
- 微信号脱敏：`wx****id`
- 主办方联系方式仅对已报名用户可见
