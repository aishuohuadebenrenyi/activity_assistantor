# 合规信息填空指南

> **Version**: v1.0.0 | **Last Updated**: 2026-03-26

本文档提供隐私政策、用户协议等法律文件中占位符的填写指南，确保上线前完成所有必要信息的填充。

---

## 一、需要填写的占位符清单

### 1.1 隐私政策 (Privacy_Policy.md / privacy.html)

| 占位符 | 位置 | 填写内容 | 示例 |
|--------|------|----------|------|
| `【YYYY】年【MM】月【DD】日` | 生效日期/更新日期 | 实际发布日期 | 2024年03月26日 |
| `【开发者姓名/个人开发者名称】` | 运营主体 | 开发者真实姓名或公司名称 | 张三 / 北京某某科技有限公司 |
| `【privacy@your-domain.com】` | 联系邮箱 | 真实的隐私相关联系邮箱 | privacy@zentro.app |
| `【省/市】` | 联系地区 | 开发者所在省市 | 北京市海淀区 |
| `(个人开发者/自然人)` | 运营主体类型 | 根据实际情况选择保留或删除 | 个人开发者保留，企业删除 |

### 1.2 用户协议 (User_Agreement.md / terms.html)

| 占位符 | 位置 | 填写内容 | 示例 |
|--------|------|----------|------|
| `【YYYY】年【MM】月【DD】日` | 生效日期/更新日期 | 实际发布日期 | 2024年03月26日 |
| `【开发者姓名/个人开发者名称】` | 运营主体 | 与隐私政策保持一致 | 张三 |
| `【support@your-domain.com】` | 联系邮箱 | 客服/支持邮箱 | support@zentro.app |
| `【省/市】` | 联系地区 | 与隐私政策保持一致 | 北京市海淀区 |
| `【运营者所在地】` | 争议解决条款 | 开发者所在地 | 北京市海淀区 |

## 二、填写步骤

### 步骤 1：确定运营主体信息

根据您的身份类型，准备以下信息：

#### 个人开发者
- 真实姓名（与身份证一致）
- 身份证号（不公开，仅备案使用）
- 联系邮箱
- 所在省市
- 手机号（不公开，仅备案和联系方式使用）

#### 企业开发者
- 公司名称（与营业执照一致）
- 统一社会信用代码
- 公司注册地址
- 联系邮箱
- 法人代表姓名

### 步骤 2：填写隐私政策

打开以下文件进行编辑：
- `docs/07_Legal/Privacy_Policy.md`
- `backend/static/legal/privacy.html`

**必须修改的内容：**

```markdown
## 1. 我们是谁

运营主体：张三（个人开发者）
联系邮箱：privacy@zentro.app
联系地区：北京市海淀区
我们设立个人信息保护联络人：同上联系方式。
```

### 步骤 3：填写用户协议

打开以下文件进行编辑：
- `docs/07_Legal/User_Agreement.md`
- `backend/static/legal/terms.html`

**必须修改的内容：**

```markdown
## 13. 联系我们

如您对本协议有任何问题，可通过以下方式联系：

- 邮箱：support@zentro.app
- 联系地区：北京市海淀区
```

**争议解决条款：**

```markdown
## 12. 法律适用与争议解决

因本协议或使用本产品发生的争议，双方应友好协商解决；协商不成的，提交北京市海淀区有管辖权的人民法院诉讼解决。
```

### 步骤 4：同步更新 HTML 文件

确保 Markdown 和 HTML 版本内容一致：
- `backend/static/legal/privacy.html`
- `backend/static/legal/terms.html`

## 三、填写注意事项

### 3.1 信息真实性要求

| 要求 | 说明 |
|------|------|
| **真实有效** | 所有联系方式必须真实可用，能够接收用户咨询 |
| **一致性** | 隐私政策和用户协议中的运营主体信息必须一致 |
| **可联系性** | 邮箱必须能够正常接收邮件，建议设置自动回复 |

### 3.2 日期填写规范

```
生效日期：首次发布日期，格式为 YYYY年MM月DD日
更新日期：最近一次修订日期，与生效日期相同表示首次发布
```

### 3.3 邮箱配置建议

建议配置以下专用邮箱：

| 邮箱用途 | 建议地址 | 说明 |
|----------|----------|------|
| 隐私相关 | privacy@your-domain.com | 处理隐私咨询、数据删除请求 |
| 用户支持 | support@your-domain.com | 处理用户问题、投诉举报 |
| 法律事务 | legal@your-domain.com | 处理法律相关事务（可选） |

### 3.4 地区填写规范

- 个人开发者：填写身份证上的省市
- 企业开发者：填写营业执照上的注册地址省市

格式示例：
- `北京市海淀区`
- `上海市浦东新区`
- `广东省深圳市南山区`

## 六、常见问题

### Q1：个人开发者需要填写公司信息吗？

不需要。个人开发者填写真实姓名即可，标注为"个人开发者"。

### Q2：邮箱可以使用个人邮箱吗？

可以，但建议使用与域名相关的专业邮箱（如 privacy@your-domain.com），更显专业。

### Q3：生效日期应该填什么时候？

填写实际上线发布日期。如果已经发布，填写发布日期；如果尚未发布，填写预计上线日期。

### Q4：更新日期和生效日期需要不同吗？

首次发布时两者相同。后续修订政策时，更新日期改为修订日期。

### Q5：争议解决条款中的法院如何选择？

选择开发者所在地的基层人民法院。例如：
- 北京市海淀区 → 北京市海淀区人民法院
- 上海市浦东新区 → 上海市浦东新区人民法院
