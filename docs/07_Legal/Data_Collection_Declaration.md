# 数据收集声明

> **Version**: v1.0.0 | **Last Updated**: 2026-03-26

本文档详细说明 Zentro 活动助手收集的用户数据类型、用途、存储方式及用户权利，用于满足 iOS App Store 和微信小程序的数据披露要求。

---

## 一、数据收集概览

### 1.1 数据收集原则

Zentro 遵循以下数据收集原则：

| 原则 | 说明 |
|------|------|
| **最小必要** | 仅收集实现功能所必需的数据 |
| **目的明确** | 每项数据收集都有明确的使用目的 |
| **用户知情** | 用户在使用前了解数据收集情况 |
| **安全保护** | 采取合理措施保护用户数据安全 |

### 1.2 数据收集清单总览

| 数据类型 | 收集场景 | 是否必需 | 存储期限 |
|----------|----------|----------|----------|
| 手机号 | 注册/登录/报名 | 是 | 账号存续期 |
| 微信 OpenID | 微信登录 | 是（小程序端） | 账号存续期 |
| 昵称/头像 | 用户设置 | 否 | 账号存续期 |
| 活动信息 | 创建活动 | 是 | 活动存续期 |
| 报名信息 | 报名活动 | 是 | 活动存续期 |
| 签到记录 | 现场签到 | 是 | 活动存续期 |
| 设备日志 | 服务运行 | 自动 | 30天 |

## 二、详细数据收集说明

| **用户权利** | 可查看、更正、申请删除 |

**iOS App Store 数据类型映射**：
- 类型：联系信息 → 电话号码
- 用途：App 功能
- 是否追踪：否

**微信小程序数据类型映射**：
- 类型：手机号
- 用途：用户身份验证、活动报名

#### 微信 OpenID

| 属性 | 说明 |

| **使用目的** | 微信用户身份识别、登录验证 |
| **是否必需** | 是（小程序端登录必需） |

- 不适用（仅小程序端使用）

**微信小程序数据类型映射**：
- 类型：微信昵称、头像（如用户授权）

## 四、数据存储与安全

### 4.1 存储位置

- 数据存储于中华人民共和国境内的服务器
- 不进行跨境数据传输

### 4.2 存储期限

| 数据类型 | 存储期限 | 说明 |
|----------|----------|------|
| 账号数据 | 账号存续期 | 注销后删除或匿名化 |
| 活动数据 | 活动存续期 | 删除活动后删除相关数据 |
| 报名数据 | 活动存续期 | 活动删除后删除 |
| 日志数据 | 30天 | 自动清理 |

### 4.3 安全措施

| 措施 | 说明 |
|------|------|
| 传输加密 | HTTPS 加密传输 |
| 存储安全 | 数据库访问控制 |
| 敏感信息脱敏 | 手机号脱敏显示 |
| 日志脱敏 | 日志中不记录敏感信息 |
| 访问控制 | 最小权限原则 |

## 五、用户权利

### 5.1 数据访问权

用户可以：
- 查看自己的账号信息
- 查看自己的报名记录
- 查看自己的签到记录

### 5.2 数据更正权

用户可以：
- 修改自己的昵称、头像、简介
- 主办方可以修改活动信息

### 5.3 数据删除权

用户可以：
- 删除自己创建的活动（同时删除相关报名和签到数据）
- 取消报名（活动开始前）
- 申请注销账号（注销后数据删除或匿名化）

### 5.4 账号注销

- 入口：我的 → 账号管理 → 注销账号
- 冷静期：15天
- 冷静期内可重新登录撤销注销
- 冷静期后数据删除或匿名化

## 七、微信小程序数据披露

### 7.1 小程序隐私协议配置

在微信小程序后台需要配置以下内容：

#### 收集的用户信息

| 信息类型 | 用途说明 | 是否必填 |
|----------|----------|----------|
| 手机号 | 用于用户登录、活动报名、联系沟通 | 是 |
| 微信昵称/头像 | 用于用户信息展示 | 否 |
| 位置信息 | 用于活动地点导航（预留功能） | 否 |

#### 使用的接口

| 接口名称 | 用途说明 |
|----------|----------|
| wx.login | 用户登录 |
| wx.getUserProfile | 获取用户昵称头像 |
| wx.getLocation | 获取位置信息（预留） |
| wx.scanCode | 扫码签到 |
| wx.saveImageToPhotosAlbum | 保存二维码图片 |

### 7.2 隐私保护指引配置

在微信公众平台 → 设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引 中配置：

```
Zentro 活动助手小程序收集以下用户信息：

1. 手机号：用于用户登录验证、活动报名、联系沟通
2. 微信昵称/头像：用于用户信息展示（可选）
3. 位置信息：用于活动地点导航（可选，需用户授权）

我们承诺：
- 仅在实现功能所必需的范围内使用用户信息
- 不向第三方出售用户信息
- 采取合理措施保护用户数据安全
- 用户可申请删除或注销账号

联系方式：【privacy@your-domain.com】
```
