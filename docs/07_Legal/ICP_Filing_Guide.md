# ICP 备案指南

> **Version**: v1.0.0 | **Last Updated**: 2026-03-26

本文档详细说明如何进行网站 ICP 备案，这是在中国大陆提供互联网服务的必要合规步骤。

---

## 一、ICP 备案概述

### 1.1 什么是 ICP 备案

ICP 备案（Internet Content Provider 备案）是中国大陆网站必须进行的备案登记，由工信部管理。根据《互联网信息服务管理办法》，所有在中国大陆提供服务的网站都必须进行 ICP 备案。

### 1.2 备案类型

| 类型 | 适用场景 | 示例 |
|------|----------|------|
| **ICP 备案** | 非经营性网站 | 个人博客、企业官网 |
| **ICP 经营许可证** | 经营性网站 | 电商平台、在线支付 |

Zentro 作为活动管理工具，属于非经营性网站，只需进行 ICP 备案。

### 1.3 备案必要性

- **法律要求**：未备案网站不得在中国大陆提供服务
- **微信小程序要求**：小程序服务器域名必须完成备案
- **iOS App Store 要求**：App 后端服务需要备案域名
- **云服务商要求**：国内云服务器必须绑定已备案域名

## 二、备案准备

### 2.1 备案所需材料

#### 个人开发者

| 材料 | 说明 |
|------|------|
| 身份证正反面照片 | 清晰、完整、无遮挡 |
| 手持身份证照片 | 需看清身份证信息 |
| 域名证书 | 域名注册商提供 |
| 手机号 | 用于接收验证码 |
| 邮箱 | 用于接收备案通知 |

#### 企业开发者

| 材料 | 说明 |
|------|------|
| 营业执照副本 | 加盖公章 |
| 法人身份证正反面 | 清晰照片 |
| 网站负责人身份证 | 正反面照片 |
| 网站负责人手持身份证 | 需看清身份证信息 |
| 域名证书 | 域名注册商提供 |
| 授权书 | 法人授权网站负责人办理备案 |
| 手机号 | 用于接收验证码 |
| 邮箱 | 用于接收备案通知 |

### 2.2 域名要求

- 域名必须已注册并完成实名认证
- 域名注册信息与备案主体一致
- 域名有效期大于 3 个月

### 2.3 服务器要求

- 服务器位于中国大陆
- 已购买云服务器并获取公网 IP
- 服务器提供商具有备案资质

## 三、备案流程

### 3.1 流程概览

```
┌─────────────────────────────────────────────────────────────────┐
│                        ICP 备案流程                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐  │
│  │ 准备材料 │────▶│ 提交申请 │────▶│ 云商初审 │────▶│ 管局审核 │  │
│  └─────────┘     └─────────┘     └─────────┘     └─────────┘  │
│       │               │               │               │        │
│       ▼               ▼               ▼               ▼        │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 1-2天          1-2天          1-3天         10-20天     │   │
│  │ 准备证件       填写信息       云商审核       管局审批     │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  ┌─────────┐     ┌─────────┐                                   │
│  │ 备案成功 │────▶│ 添加备案 │                                   │
│  │         │     │ 号到网站 │                                   │
│  └─────────┘     └─────────┘                                   │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 详细步骤

#### 步骤 1：选择云服务商备案系统

根据服务器提供商选择备案入口：

| 云服务商 | 备案入口 |
|----------|----------|
| 阿里云 | https://beian.aliyun.com |
| 腾讯云 | https://cloud.tencent.com/product/ba |
| 华为云 | https://beian.huaweicloud.com |
| 百度云 | https://cloud.baidu.com/product/beian.html |

#### 步骤 2：注册备案账号

1. 使用云服务商账号登录备案系统
2. 完成实名认证
3. 绑定手机号和邮箱

#### 步骤 3：填写主体信息

```
主体信息：
├── 主体性质：个人/企业
├── 主体名称：姓名/公司名称
├── 证件类型：身份证/营业执照
├── 证件号码：身份证号/统一社会信用代码
├── 证件地址：身份证/营业执照地址
├── 联系方式：手机号
└── 通讯地址：实际联系地址
```

#### 步骤 4：填写网站信息

```
网站信息：
├── 网站名称：Zentro 活动助手
├── 网站域名：zentro.app
├── 网站首页：https://zentro.app
├── 网站服务内容：其他
├── 网站语言：中文
├── 前置审批：无
└── 网站简介：活动管理工具，提供活动创建、报名、签到等功能
```

#### 步骤 5：上传材料

上传准备好的证件照片：
- 身份证正反面
- 手持身份证照片
- 域名证书
- 其他证明材料（如需要）

#### 步骤 6：提交审核

1. 检查所有信息是否正确
2. 确认提交
3. 等待云服务商初审

#### 步骤 7：云服务商初审

- 时间：1-3 个工作日
- 内容：云服务商审核材料完整性和真实性
- 可能需要：电话核实、补充材料

#### 步骤 8：管局审核

- 时间：10-20 个工作日
- 内容：工信部审核备案申请
- 结果：短信和邮件通知

#### 步骤 9：备案成功

- 收到备案号
- 在网站底部添加备案号
- 链接到工信部备案查询页面

## 四、备案信息填写指南

### 4.1 网站名称规范

**允许的命名方式：**
- 个人：姓名 + 个人博客/主页/网站
- 企业：公司名称/品牌名称 + 官网/网站

**不允许的命名方式：**
- 包含"中国"、"中华"、"国家"等字样
- 包含行业通用词汇（如"活动网"、"报名网"）
- 包含敏感词汇
- 过于简单（如"我的网站"）

**Zentro 推荐命名：**
- 个人：张三的活动管理工具
- 企业：Zentro 活动助手官网

### 4.2 网站简介示例

```
Zentro 活动助手是一款活动管理工具，为主办方提供活动创建、编辑、
管理、签到核销等功能，为参与者提供活动浏览、报名、电子票展示
等功能。本网站仅提供工具服务，不涉及经营性内容。
```

### 4.3 网站服务内容选择

| 选项 | 是否选择 | 说明 |
|------|----------|------|
| 综合门户 | ❌ | 不适用 |
| 网络媒体 | ❌ | 不适用 |
| 电子邮件 | ❌ | 不适用 |
| 即时通信 | ❌ | 不适用 |
| 论坛/社区 | ❌ | 不适用 |
| 电子商务 | ❌ | 不涉及交易 |
| 网络游戏 | ❌ | 不适用 |
| 其他 | ✅ | 选择此项 |

## 五、备案后操作

### 5.1 添加备案号到网站

备案成功后，必须在网站底部显示备案号：

```html
<!-- 网站底部添加 -->
<footer>
  <p>
    Copyright © 2024 Zentro. All Rights Reserved.
    <a href="https://beian.miit.gov.cn/" target="_blank">
      京ICP备XXXXXXXX号-1
    </a>
  </p>
</footer>
```

### 5.2 公安备案（可选）

部分省市要求完成公安备案：

1. 访问 [全国互联网安全管理服务平台](http://www.beian.gov.cn)
2. 注册账号并登录
3. 填写网站信息
4. 提交审核

### 5.3 备案变更

以下情况需要变更备案：

| 变更类型 | 操作 |
|----------|------|
| 域名变更 | 添加新域名或修改域名 |
| 主体变更 | 变更主体信息 |
| 网站名称变更 | 修改网站信息 |
| 服务器变更 | 如跨云商需要重新备案 |

## 六、常见问题

### Q1：备案需要多长时间？

- 云商初审：1-3 个工作日
- 管局审核：10-20 个工作日
- 总计：约 15-25 个工作日

### Q2：备案期间网站可以访问吗？

不可以。备案期间网站必须关闭，直到备案成功。

### Q3：个人可以备案多个网站吗？

可以。一个主体可以备案多个网站，但需要分别提交申请。

### Q4：备案被驳回怎么办？

根据驳回原因修改后重新提交。常见驳回原因：
- 材料不清晰
- 信息填写错误
- 网站名称不规范
- 网站内容与描述不符

### Q5：使用境外服务器需要备案吗？

不需要。但微信小程序要求服务器域名必须备案，所以建议使用国内服务器。

### Q6：备案号会过期吗？

不会过期，但需要每年进行年审（部分省市要求）。

## 七、备案检查清单

### 7.1 备案前检查

- [ ] 域名已注册并实名认证
- [ ] 域名注册信息与备案主体一致
- [ ] 服务器已购买（中国大陆）
- [ ] 证件材料已准备齐全
- [ ] 网站内容已准备（或临时关闭页面）

### 7.2 备案中检查

- [ ] 主体信息填写正确
- [ ] 网站信息填写正确
- [ ] 材料上传完整清晰
- [ ] 手机号可正常接听
- [ ] 邮箱可正常接收邮件

### 7.3 备案后检查

- [ ] 收到备案号
- [ ] 网站底部已添加备案号
- [ ] 备案号链接正确
- [ ] 网站可正常访问
- [ ] 微信小程序域名配置已更新
