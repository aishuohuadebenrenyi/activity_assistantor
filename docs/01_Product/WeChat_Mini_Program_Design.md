# 微信小程序端差异化设计说明书

## 1. 核心定位
- **App 端**: 活动管理工作台（B端）。面向主办方，提供创建、编辑、管理、核销等全套功能。
- **小程序端**: 活动参与连接器（C端）。面向普通用户，提供扫码报名、查看电子票、出示核销码等轻量级功能。

## 2. 交互流程差异

### 2.1 启动与首页
- **App**: 启动后进入“活动列表”，展示所有活动，右下角有“创建活动”悬浮按钮。
- **小程序**: 
    - **冷启动**: 默认进入“我的报名”列表（票夹）。顶部提供“扫一扫”功能，方便扫描主办方二维码加入新活动。
    - **扫码进入**: 直接跳转至“活动详情页”，进行报名或查看。

### 2.2 底部导航 (TabBar)
- **App**: `首页` | `创建` | `我的`
- **小程序**: `我的报名` | `个人中心`

### 2.3 活动详情页
- **App**:
    - 显示活动统计（浏览量、签到率）。
    - 显示“编辑”、“分享”、“报名管理”入口。
    - 底部按钮：“开始签到” (进入扫码模式，主办方扫用户)。
- **小程序**:
    - 隐藏活动统计数据。
    - 隐藏所有管理入口。
    - 底部按钮：
        - 未报名 -> “立即报名” (**注：当前版本为模拟演示，不涉及真实支付**)
        - 已报名 -> “查看电子票”

### 2.4 电子票/签到页 (Ticket)
- **小程序特有**:
    - 展示活动关键信息（时间、地点、简介）。
    - 展示入场二维码（供主办方扫描）。
    - **自助签到**：提供“扫码签到”按钮，允许用户扫描现场张贴的活动二维码完成签到（适用于开放式活动）。

### 2.5 个人中心
- **App**: 展示主办方身份认证、活动发布统计。
- **小程序**: 展示参与者身份、参与记录统计。隐藏与管理相关的入口。

## 3. 技术实现策略
利用 `uni-app x` 的条件编译功能 (`#ifdef APP-PLUS`, `#ifdef MP-WEIXIN`) 实现单套代码库的多端差异化渲染。

### 3.1 pages.json
通过条件编译定义两套 `tabBar` 配置。

### 3.2 页面逻辑
- **detail.uvue**: 针对小程序隐藏 `stats-card` 和 `tools-card`。
- **profile.uvue**: 针对小程序调整用户信息展示和统计维度。
- **my-activities.uvue**: 增强为空状态下的引导逻辑。
