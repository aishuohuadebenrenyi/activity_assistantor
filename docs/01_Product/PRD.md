## 1. 产品概述

**Zentro** 是面向活动组织者的移动端活动管理应用，聚焦"创建活动—管理报名—签到跟进—结果沉淀"闭环。

### 1.1 产品定位

| 维度 | 说明 |
|------|------|
| 产品类型 | 移动端活动管理工具 |
| 核心场景 | 活动发布、报名管理、现场签到、数据统计 |
| 技术架构 | uni-app x (UTS) + Python Flask |
| 运行平台 | iOS / Android / 微信小程序 |

### 1.2 目标用户

| 用户类型 | 描述 | 核心需求 |
|---------|------|---------|
| 社区运营 | 社群活动组织者 | 快速发布活动、管理报名名单 |
| 企业行政/HR | 企业内部活动组织者 | 员工活动管理、签到统计 |
| 培训负责人 | 培训机构/企业培训师 | 培训签到、数据导出 |
| 社群组织者 | 兴趣社群/俱乐部 | 活动发布、成员管理 |

### 1.3 核心价值

| 价值点 | 描述 | 实现方式 |
|--------|------|---------|
| 快速发起 | 简化活动创建流程，3分钟完成发布 | 表单优化、预设模板 |
| 过程可控 | 实时查看报名/签到状态，支持现场核销 | 实时数据同步、扫码核销 |
| 数据可见 | 浏览量、报名率、签到率等关键指标可视化 | 统计看板、数据导出 |

## 3. 核心功能

### 3.1 用户管理

#### 3.1.1 登录注册

| 登录方式 | 适用平台 | 说明 |
|---------|---------|------|
| 手机号验证码登录 | 全平台 | 自动注册，首次登录创建账号 |
| 微信登录 | 小程序/App | code 换取 openid |
| Apple 登录 | iOS | App Store 强制要求 |

#### 3.1.2 验证码策略

| 策略项 | 规则 |
|--------|------|
| 发送频率 | 同一手机号 60 秒内仅允许发送一次 |
| 有效期 | 5 分钟 |
| 存储方式 | 生产环境 Redis，开发环境内存字典 |

#### 3.1.3 账号注销

| 规则项 | 说明 |
|--------|------|
| 冷静期 | 15 天（符合 iOS App Store 指南 5.1.1(v)） |
| 恢复方式 | 冷静期内登录自动恢复 |
| 数据处理 | 不可逆脱敏，保留审计记录 |

### 3.2 活动管理（App 端）

#### 3.2.1 活动创建

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | String | ✅ | 活动名称 |
| type | String | 否 | 活动类型，默认"其他" |
| date | Date | ✅ | 活动日期 |
| time | Time | ✅ | 开始时间 |
| location | String | 否 | 活动地点 |
| description | Text | 否 | 活动描述 |
| capacity | Integer | 否 | 人数上限，0 表示不限 |

#### 3.2.2 活动状态

| 状态 | 判断规则 |
|------|---------|
| 即将开始 | start_time > 当前时间 |
| 进行中 | start_time ≤ 当前时间 < end_time |
| 已结束 | 当前时间 ≥ end_time |
| 已取消 | 手动设置（优先级最高） |

#### 3.2.3 内容安全

- 集成微信 msgSecCheck，自动拦截违规内容
- 校验字段：活动名称、描述、地点、微信号

### 3.3 报名与签到

#### 3.3.1 报名流程

| 步骤 | 说明 |
|------|------|
| 1. 浏览活动 | 用户通过分享链接或搜索进入活动详情 |
| 2. 填写信息 | 填写姓名、手机号 |
| 3. 提交报名 | 系统校验容量、重复报名 |
| 4. 获取凭证 | 生成签到二维码 |

#### 3.3.2 签到方式

| 方式 | 适用场景 | 说明 |
|------|---------|------|
| 扫码签到 | 参与者自助签到 | 扫描活动二维码 |
| 核销签到 | 组织者核销 | 扫描参与者签到码 |
| 手动签到 | 无扫码能力时 | 直接选择报名记录 |

#### 3.3.3 签到码安全

| 安全措施 | 说明 |
|---------|------|
| HMAC 签名 | SHA256 签名校验 |
| 有效期 | 7 天 |
| 格式验证 | CHECKIN:activity_id:registration_id:timestamp:signature |

### 3.4 数据导出

- 支持将报名名单以 CSV 格式发送至指定邮箱
- 字段：ID、姓名、电话、报名时间、是否签到、签到时间

### 3.5 离线能力

| 能力 | 说明 |
|------|------|
| 离线创建 | 断网下创建活动，恢复后自动同步 |
| 离线编辑 | 断网下编辑活动，恢复后自动同步 |
| 离线删除 | 断网下删除活动，恢复后自动同步 |
| 乐观更新 | 操作立即生效，失败自动回滚 |

## 4. 商业化规划

### 4.1 变现模式选择

| 模式 | 说明 | 适用场景 | 推荐度 |
|------|------|----------|--------|
| Freemium | 基础免费，高级功能付费 | 工具类应用 | ⭐⭐⭐ |
| 订阅制 | 按月/年付费 | 持续使用场景 | ⭐⭐ |
| 买断制 | 下载即付费 | 小众精品 | ⭐ |

### 4.2 付费功能规划

| 功能 | 免费版 | 专业版 |
|------|--------|--------|
| 活动数量 | 5 个 | 无限 |
| 报名人数 | 50 人/活动 | 无限 |
| 数据导出 | 1 次/月 | 无限 |
| 高级统计 | ❌ | ✅ |
| 团队协作 | ❌ | ✅ |

### 4.3 权益体系

| 权益键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| export.enabled | bool | true | 是否支持导出 |
| activity.max_count | int | 9999 | 活动数量上限 |
| team.enabled | bool | false | 是否支持团队协作 |

### 4.4 支付接入

| 平台 | 支付方式 | 抽成 |
|------|---------|------|
| iOS | 苹果内购 (IAP) | 30% |

## 5. 数据指标

### 5.1 核心指标

| 指标 | 定义 | 商业价值 |
|------|------|----------|
| DAU | 日活跃用户数 | 衡量产品活跃度 |
| MAU | 月活跃用户数 | 衡量产品规模 |
| 浏览量 | 活动详情页打开次数 | 衡量活动吸引力 |
| 报名人数 | 成功报名人数 | 衡量市场需求 |
| 签到率 | 实际签到/报名人数 | 衡量用户履约意愿 |
| 转化漏斗 | 浏览→报名→签到 | 识别流失环节 |

### 5.2 埋点体系

#### 5.2.1 用户生命周期事件

| 事件名 | 触发时机 |
|--------|----------|
| app_launch | 应用启动 |
| user_login | 用户登录成功 |
| user_account_deletion_pending | 账号注销进入冷静期 |
| user_account_deleted_final | 账号最终注销 |

#### 5.2.2 活动生命周期事件

| 事件名 | 触发时机 |
|--------|----------|
| activity_create_success | 活动创建成功 |
| activity_create_offline_queued | 活动创建离线入队 |
| activity_update_success | 活动更新成功 |
| activity_delete_success | 活动删除成功 |

#### 5.2.3 报名签到事件

| 事件名 | 触发时机 |
|--------|----------|
| registration_success | 报名成功 |
| registration_cancelled | 取消报名 |
| checkin_success | 签到成功 |

### 5.3 数据分析平台

- **友盟+**：用户行为分析、留存分析、漏斗分析
- **自建埋点**：业务事件上报、自定义查询
