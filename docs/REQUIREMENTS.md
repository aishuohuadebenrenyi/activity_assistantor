# 活动帮手 (Activity Assistant) 需求说明书

## 1. 引言

### 1.1 目的
本文档用于描述“活动帮手”当前版本的功能范围、页面交互规则与非功能约束，作为开发、测试和验收的统一依据。

### 1.2 背景
“活动帮手”是一款面向活动组织者的轻量级管理工具，旨在解决中小型活动（如会议、培训、聚会）在发布、报名、签到环节的效率问题。

## 2. 功能需求

### 2.1 导航与页面结构
- 底部 TabBar 必须包含并仅包含三个入口：**首页**、**创建**、**我的**。
- 非 TabBar 页面（登录、详情、报名人员、分享、创建成功、编辑资料、关于）通过页面跳转进入。
- 页面主题需统一为浅灰背景 + 白色卡片风格。

### 2.2 登录与账号
- 支持微信一键登录与手机号验证码登录两种模式。
- 手机号需执行格式校验后才能发起验证码请求或登录。
- 验证码发送后需展示倒计时，倒计时期间禁用重复发送。
- 登录中状态需禁止重复点击并提供加载提示。
- 支持查看与编辑个人资料，支持退出登录与注销账号（二次确认）。

### 2.3 首页（活动列表）
- 展示活动统计信息与活动列表。
- 支持活动状态筛选：全部、进行中、即将开始、已结束。
- 搜索区采用折叠设计，仅在用户点击搜索入口后展开。
- 展开后支持按活动名称或地点关键词检索。
- 滚动时支持 TabBar 显隐联动：
  - 向下滑动超过阈值时隐藏；
  - 向上滑动时显示；
  - 搜索区展开时应保持显示，避免交互抖动。
- 空列表场景需提供“去创建活动”引导入口。

### 2.4 创建活动
- 必填项：活动名称、活动类型、活动日期、活动时间。
- 可选项：地点、人数上限、活动介绍。
- 支持键盘避让：键盘弹出时动态调整底部留白，确保输入与提交按钮可见。
- 提交按钮文案为“立即创建活动”，提交过程中需防重复提交。
- 创建成功后进入成功页，并支持返回首页或继续查看后续操作。

### 2.5 活动详情
- 展示活动统计（浏览量、报名人数、签到人数、签到率）。
- 展示活动详情摘要（日期、时间、人数上限、地点）。
- 详细信息支持展开/收起与编辑保存。
- 编辑入口位于“详细信息”模块头部右上角，文案在“编辑/完成”间切换。
- 支持活动工具跳转：报名情况、分享活动。
- 活动不存在时需展示异常态并提供返回首页入口。

### 2.6 报名人员与签到
- 展示报名统计（报名人数、已签到、未签到、签到率）。
- 报名人员模块支持搜索、筛选（全部/已签到/未签到）。
- 支持单人签到状态切换并实时更新统计数据。
- 导出入口位于“报名人员”模块头部右侧。
- 当前导出能力可为占位状态（提示“开发中”），但入口与交互反馈必须存在。

### 2.7 分享与个人中心
- 分享页需展示活动基本信息与分享入口（复制链接等）。
- 个人中心需展示总活动数、进行中活动数、总参与人次。
- 通用设置需提供主题、通知、帮助与支持入口。
- 全局关键交互元素应具备统一触摸反馈。

## 3. 非功能需求

### 3.1 性能要求
- 页面加载时间不超过 1.5 秒。
- 列表滚动流畅，无明显卡顿（FPS >= 55）。

### 3.2 兼容性
- 支持 iOS 和 Android 主流移动设备。
- 适配刘海屏及底部安全区域（Safe Area）。

### 3.3 易用性
- 界面简洁，符合移动端主流操作习惯。
- 关键操作（如删除、注销）需提供二次确认弹窗。
- 关键入口（编辑、导出、新建）需放置在所属功能模块头部，提升可发现性。

### 3.4 界面设计
- 主色调：系统蓝 (#007AFF)。
- 背景色：#F2F2F7 (浅灰)，营造沉浸式体验。
- 顶部导航栏与页面背景融合，无突兀分割线。
