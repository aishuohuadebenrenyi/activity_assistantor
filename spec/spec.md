# 活动帮手 (Activity Assistant) 项目架构分析与上线差距评估

> **Version**: v1.2.0 | **Created**: 2026-03-23 | **Updated**: 2026-03-23

## 1. 项目概述

### 1.1 产品定位
**活动帮手** 是面向活动组织者的移动端活动管理应用，聚焦"创建活动—管理报名—签到跟进—结果沉淀"闭环。

### 1.2 目标用户
- 社区运营
- 企业行政/HR
- 培训负责人
- 社群组织者

### 1.3 多端策略
| 平台 | 角色 | 核心功能 |
|------|------|----------|
| iOS/Android App | 主办方/管理员 | 创建活动、管理报名、扫码核销、导出数据 |
| 微信小程序 | 参与者/用户 | 浏览活动、在线报名、查看电子票、扫码签到 |

## 3. 技术架构分析

### 3.1 前端架构

#### 3.1.1 技术栈
| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 框架 | uni-app x | 基于 Vue 3 + UTS，纯原生渲染 |
| 状态管理 | Vue Reactivity | 响应式 Store (`store/index.uts`) |
| 网络层 | 自研封装 | `request.uts` 统一处理 JWT 注入与 Mock 切换 |
| 离线机制 | 自研队列 | `offline_queue.uts` 实现非 GET 请求的本地持久化队列 |

#### 3.1.2 目录结构
```
frontend/
├── adapters/          # 平台适配层
├── components/        # 公共组件 (ActivityItem, ParticipantItem, StatCard)
├── mock/              # Mock 数据层
├── pages/             # 页面组件
│   ├── about/         # 关于页
│   ├── activities/    # 活动列表
│   ├── activity/      # 活动详情/创建/报名/签到/分享
│   ├── auth/          # 登录认证
│   ├── profile/       # 个人中心
│   ├── user/          # 用户相关
│   └── webview/       # H5 容器
├── static/            # 静态资源
├── store/             # 全局状态
├── utils/             # 工具函数
├── App.uvue           # 应用入口
├── manifest.json      # 应用配置
└── pages.json         # 路由配置
```

#### 3.1.3 核心特性
- **离线优先**: 支持断网下执行关键操作，恢复后自动同步
- **幂等性保障**: 前端为所有非 GET 请求生成唯一 `Idempotency-Key`
- **条件编译**: 通过 `#ifdef` 实现多端差异化

### 3.2 后端架构

#### 3.2.1 技术栈
| 组件 | 技术选型 | 版本 |

## 5. 上线差距分析

### 5.1 阻塞性问题 (P0 - 必须解决)

#### 5.1.1 代码层面
| 问题 | 当前状态 | 影响 | 解决方案 |
|------|----------|------|----------|
| 短信服务为 Mock | 仅打印日志 | 用户无法收到验证码 | 集成阿里云短信 SDK |
| 验证码内存存储 | 单进程限制 | 多进程不一致 | 迁移到 Redis |
| 前端账号注销未调用 API | 仅显示提示 | 功能不完整 | 实现接口调用 |

#### 5.1.2 配置与部署
| 问题 | 当前状态 | 影响 | 解决方案 |
|------|----------|------|----------|
| Mock 模式未关闭 | `USE_MOCK: true` | 所有请求走本地 Mock | 切换为 `false` 并配置真实后端地址 |
| 后端密钥使用默认值 | `dev-secret-key-change-in-prod` | 安全风险极高 | 通过环境变量注入生产密钥 |
| 微信配置为 Mock | `wx1234567890abcdef` | 微信登录/内容安全无法工作 | 配置真实 AppID/Secret |

#### 5.1.3 法律合规
| 问题 | 当前状态 | 影响 | 解决方案 |
|------|----------|------|----------|
| 隐私政策占位符 | `【开发者姓名】` 等占位 | 审核必拒 | 填写真实运营主体信息 |
| ICP 备案未完成 | 无备案域名 | 国内服务器违法 | 完成工信部 ICP 备案 |

#### 5.1.4 iOS App Store 特有
| 问题 | 当前状态 | 影响 | 解决方案 |
|------|----------|------|----------|
| Apple 登录未对接后端 | 仅前端 UI | 审核必拒 | 实现后端 Apple Token 验证 |
| App 图标缺失 | 配置为空 | 审核必拒 | 准备各尺寸图标 |
| 启动页缺失 | 配置为空 | 审核可能被拒 | 准备启动页素材 |

## 7. 风险评估

| 风险项 | 风险等级 | 说明 | 缓解措施 |
|--------|----------|------|----------|
| FC 冷启动延迟 | 中 | 首次请求响应慢 | 配置预留实例，优化依赖加载 |
| 审核被拒 | 高 | iOS/小程序审核严格 | 提前阅读审核指南，确保合规 |
| 数据丢失 | 高 | 无备份策略 | RDS 自动备份 + 跨地域容灾 |
| 安全漏洞 | 中 | 独立开发安全经验不足 | 安全测试，代码审计 |
| 费用超支 | 低 | 云服务按量计费 | 设置预算告警，监控用量 |
