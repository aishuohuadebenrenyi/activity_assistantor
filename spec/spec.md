# Zentro 上线待办事项

> **Version**: v1.0.0 | **Created**: 2026-03-23 | **Updated**: 2026-03-24

## 项目概述

**Zentro** 是面向活动组织者的移动端活动管理应用，聚焦"创建活动—管理报名—签到跟进—结果沉淀"闭环。

### 多端策略

| 平台 | 角色 | 核心功能 |
|------|------|----------|
| iOS/Android App | 主办方/管理员 | 创建活动、管理报名、扫码核销、导出数据 |
| 微信小程序 | 参与者/用户 | 浏览活动、在线报名、查看电子票、扫码签到 |

## 建议上线路径

### 阶段一：基础设施准备 (1 周)
1. 创建阿里云账号，开通所需服务
2. 创建 RDS MySQL 实例
3. 创建 Redis 实例
4. 配置 VPC 网络
5. 申请域名并完成 ICP 备案

### 阶段二：后端部署 (1 周)
1. 配置环境变量
2. 部署到 FC 测试环境
3. 配置 API 网关和自定义域名

### 阶段三：内测版 (1 周)
1. 关闭前端 Mock 模式
2. 配置真实后端地址
3. 完成核心功能测试
4. 邀请种子用户内测

### 阶段四：小程序上线 (1 周)
1. 配置小程序域名
2. 提交微信审核
3. 正式发布

### 阶段五：iOS App Store (2-3 周)
1. 准备应用素材
2. 注册 Apple 开发者账号
3. 提交 App Store 审核
4. 正式发布

## 风险评估

| 风险项 | 风险等级 | 说明 | 缓解措施 |
|--------|----------|------|----------|
| FC 冷启动延迟 | 中 | 首次请求响应慢 | 配置预留实例，优化依赖加载 |
| 审核被拒 | 高 | iOS/小程序审核严格 | 提前阅读审核指南，确保合规 |
| 数据丢失 | 高 | 无备份策略 | RDS 自动备份 + 跨地域容灾 |
| 安全漏洞 | 中 | 独立开发安全经验不足 | 安全测试，代码审计 |
| 费用超支 | 低 | 云服务按量计费 | 设置预算告警，监控用量 |
