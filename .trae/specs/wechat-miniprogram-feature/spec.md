# 微信小程序功能 Spec (WeChat Mini Program Feature)

## Why
目前 App 仅支持 Android/iOS，为了降低用户参与门槛，利用微信生态进行裂变传播，需要支持微信小程序端。
核心场景：
1.  **快速报名**：用户扫码直接进入小程序报名，无需下载 App。
2.  **便捷签到**：提供多种签到方式，适应不同规模和场景的活动。

## What Changes

### 1. 页面适配与新增
-   **活动详情页 (`pages/activity/detail/detail.uvue`)** [Modified]
    -   适配小程序环境：隐藏 App 特有的导航栏（使用微信原生导航）。
    -   新增“微信一键授权”登录/报名按钮。
    -   新增分享给好友/朋友圈功能。
-   **登录页 (`pages/auth/login.uvue`)** [Modified]
    -   新增微信小程序登录逻辑（`uni.login` + `getPhoneNumber`）。
-   **我的报名页 (`pages/user/my-activities.uvue`)** [New]
    -   展示用户已报名的活动列表。
    -   点击活动进入凭证页。
-   **报名凭证页 (`pages/activity/ticket.uvue`)** [New]
    -   展示活动信息 + 签到二维码（用于被扫）。
    -   支持“扫一扫”功能（用于自助签到）。

### 2. 交互流程设计

#### 核心流程：扫码报名
1.  **扫码**：用户扫描活动海报二维码。
2.  **落地**：进入小程序 `detail` 页，获取活动信息。
3.  **报名**：
    -   *未登录*：点击“立即报名” -> 弹出微信手机号授权 -> 自动注册/登录 -> 完成报名。
    -   *已登录*：点击“立即报名” -> 完成报名。
4.  **反馈**：报名成功，跳转至 `ticket` 页或提示关注公众号。

#### 核心流程：签到方式 (Check-in Methods)
除了主办方在 App 列表里手动勾选签到外，新增以下两种方式：

**方式 A：主办方扫用户 (Host Scan User) - 适用于中大型活动**
1.  **用户**：在小程序“我的报名”中打开凭证，出示二维码。
2.  **主办方**：使用 App 端“扫一扫”功能，扫描用户二维码。
3.  **结果**：App 端提示“核销成功”，数据实时同步。

**方式 B：用户扫主办方 (User Scan Host) - 适用于小型聚会/自助签到**
1.  **主办方**：在 App 端活动详情页展示“签到二维码”。
2.  **用户**：使用小程序“扫一扫”或微信“扫一扫”扫描该码。
3.  **校验**：(可选) 校验用户地理位置是否在活动地点附近。
4.  **结果**：小程序端提示“签到成功”。

## Impact
-   **App 端**：需新增“扫一扫”核销功能，以及生成“活动签到码”的功能。
-   **Backend**：需新增微信登录接口、二维码生成/解析接口、签到状态更新接口。
-   **Frontend**：需处理小程序特有的 API 兼容性（如 `uni.login`）。

## ADDED Requirements

### Requirement: 微信一键登录
系统应支持使用微信手机号快速登录/注册。
-   **WHEN** 用户在小程序端点击报名且未登录
-   **THEN** 弹出手机号授权窗口，授权成功后自动完成登录。

### Requirement: 报名凭证 (Ticket)
系统应为每个报名的用户生成唯一的核销凭证（二维码）。
-   内容包含：`activity_id`, `user_id`, `timestamp`, `signature`。

### Requirement: 扫码核销 (Scan to Check-in)
系统应支持双向扫码签到。
-   App 端扫用户凭证 -> 核销成功。
-   用户扫活动码 -> 签到成功。

## MODIFIED Requirements
### Requirement: 活动详情页
-   增加“分享”按钮，支持生成小程序卡片。
-   底部操作栏适配：在小程序端显示“授权报名”而非单纯的跳转登录。
